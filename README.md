# Reinforcement Learning-Based Autonomous Obstacle Avoidance System Using LiDAR

## Objective

To develop an autonomous mobile robot that uses LiDAR sensor data and Reinforcement Learning to navigate safely while avoiding obstacles.

# Technologies Used

| Technology | Why We Use It |
|------------|---------------|
| **Python 3.10** | Primary programming language used for developing ROS2 nodes, processing LiDAR data, implementing reinforcement learning algorithms, and controlling the robot due to its simplicity and extensive AI ecosystem. |
| **ROS2 Humble** | Robotics middleware that enables communication between different robot components (LiDAR, navigation, motor controller, etc.) using nodes, topics, services, and actions. It provides a modular and scalable architecture for robotics applications. |
| **Gazebo** | A realistic robotics simulator used to create virtual environments for testing and training the robot safely before deploying algorithms on real hardware. |
| **PyTorch** | Deep learning framework used to build and train neural networks required for reinforcement learning algorithms such as DQN and PPO. |
| **Stable-Baselines3** | Reinforcement learning library that provides reliable implementations of state of the art RL algorithms, allowing faster development without implementing algorithms from scratch. |
| **LiDAR Sensor** | Provides accurate distance measurements of surrounding obstacles, enabling the robot to perceive its environment and make navigation decisions. |
